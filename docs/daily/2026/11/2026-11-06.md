## 3. 可实际运行的开源项目

### LichtFeld Studio：从训练研究到可编排生产的集中更新

- [Noise Guided Splatting / PR #3992](https://github.com/MrNeRF/LichtFeld-Studio/pull/3992)：`--noise-infill-mesh` 生成冻结范围内的 opaque changing-noise splats；`--eval-green-infill` 做独立指标与 surface opacity score。适合透明洞、薄表面与闭合物体实验，不适合没有 watertight mesh 的一般照片集。
- [Python hook payload / PR #3989](https://github.com/MrNeRF/LichtFeld-Studio/pull/3989)：payload 新增 iteration、loss、num_splats、refining/paused/iterations，终态区分 completed/stopped/failed/unknown；`SplatData.shN_rows` 可按行提取 SH-rest 且长传输释放 GIL。自动评估、训练监控与 Python adapter 更容易做得稳定。
- [Python Camera 生命周期 / PR #3996](https://github.com/MrNeRF/LichtFeld-Studio/pull/3996)：Camera handle 保活 dataset；mask/depth 缺失返回 None；Scene.add_splat 校验 shape/row count；无 dataset 时 scene_center 返回 None，避免悬空引用与静默错误。
- [训练保护](https://github.com/MrNeRF/LichtFeld-Studio/commit/86fd60f374af671ffb3dc8718fd5e80e031a7f8d)：背景图尺寸不匹配直接拒绝，避免错误像素平面乃至小 buffer 越界；FastGS 与 gsplat/GUT path 都覆盖。
- [较低 max-cap 恢复](https://github.com/MrNeRF/LichtFeld-Studio/commit/77881edd1e3dc7bcac7537ec31888a19db8c233b)：恢复项目时允许降低 `--max-cap`，对多余未冻结/未删除 rows 做确定性随机裁剪，densification 后继续遵守 cap。
- [多 checkpoint standalone project](https://github.com/MrNeRF/LichtFeld-Studio/commit/e42311fdcd64d39bf07e774ba8dba4ece6a53b62)：`--save-project-at-iter` 可在多个迭代点后台写独立 `.licht`；后续修复保留原项目其他 node/payload 与嵌入 dataset。

### visloc-rs

[merge c73978e7](https://github.com/rsasaki0109/visloc-rs/commit/c73978e7dec898536de671aae42f48b9acbe97a2) 把 SIFT detect/describe 与 matching 放到 WebGPU，verification/mapper 留在 CPU；每次 dispatch 限 16 对以避开 Windows 2 秒 watchdog，作者称 64 对会重置 AMD RDNA2 iGPU。其 u8 `dot4U8Packed` 在该 iGPU 反而比 f32 descriptor 慢 2.4×，说明“更低位宽必然更快”不成立。随后 [merge d081173a](https://github.com/rsasaki0109/visloc-rs/commit/d081173a15d8929723124e9bec8512ce3caa647b) 补齐 COLMAP zip，形成纯浏览器相机求解 → 标准数据集出口。

### Gaussian Splat Lite

[4615af69](https://github.com/gaussian-splatting-lite/gaussian-splatting-lite/commit/4615af69f7e46fd0f5f713101053645008f04efb) 是 main 上的内部格式/API 改动，而非 release。现有模型文件据维护者说明兼容；运行中的旧 viewer 不应与新 decoder 热混用。测试应同时记录 quaternion angular error、解码峰值内存、SPZ/SOG 首帧时间与截图差异。

## 6. Compression / Format / LOD / Streaming

- **Streamed SOG / LOD**：SplatTransform 首次把 `antialiased` / `2dgs` 写进 `lod-meta.json`。它解决“流式层级知道多少 splats，却不知道它们应按哪种模型解释”的语义缺口；没有改变随机访问、Gaussian budget 或 chunk size。
- **Packed rotation**：GSL 改为 32-bit smallest-three，提升旋转精度并允许 packed pass-through；现阶段只是 main 变更，未出现 tag。
- **BudgetSplat**：[arXiv:2611.06593](https://arxiv.org/abs/2611.06593) 把存储/渲染预算前移到 feed-forward reconstruction： preservation ratio 定义上限，coverage-aware selection 可能进一步得到更小的实际集合。论文未公开 absolute throughput、浏览器格式或代码。<!-- arxiv:2611.06593 -->
- SPZ、compressed PLY、glTF KHR_gaussian_splatting、OpenUSD、3D Tiles、MPEG GSC、Khronos/W3C WebGPU 在增量窗口内未核实到新批准版本或兼容性变更。
