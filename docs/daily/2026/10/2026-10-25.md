## 3. 可实际运行的开源项目

### Pryme8 Splat Lab：浏览器内多 primitive 可微训练

[Pryme8/splat-lab](https://github.com/Pryme8/splat-lab) 是今天最有实验价值的新项目。它基于 Babylon.js 9.32 和 WebGPU compute，不需要后端或构建步骤；[在线 demo](https://pryme8.github.io/splat-lab/) 可直接打开。输入包括 mesh（GLB/glTF/OBJ/STL）、Gaussian（PLY/SPLAT/SPZ）、PLY point cloud 与 SDF DSL，训练目标可选择经典 3DGS、Gaussian point、triangle 和 3D convex splats。

代码通路不是套壳 viewer：它先渲染 dense teacher views，再由 WGSL compute 做投影、prefix sum、key duplication、4-bit LSD radix sort、tile 内 front-to-back compositing，并对位置、scale、rotation、triangle corner、convex point、颜色与 opacity 做解析 backward 和 Adam 优化。每 250 steps 还有类 MCMC relocation。

本窗口的关键提交：

- [fcb7cbb](https://github.com/Pryme8/splat-lab/commit/fcb7cbb708e7e4bfd0b8685e3bf00da273f77770)：用 GPU-sized sort 与 indirect dispatch 去掉 CPU readback，可排队最多 4 个训练 step。
- [79d676e4](https://github.com/Pryme8/splat-lab/commit/79d676e4f8cb37b979eb92442f7ff22fe6796145)：梯度先在 workgroup memory 累积，再做全局原子写，并加入 GPU profiler。
- [bf394a36](https://github.com/Pryme8/splat-lab/commit/bf394a36ecf2ca6375d497914d1269a9f9dab916)：超过上限时自动降低 primitive 数量，而不是直接拒绝训练。

作者在 RTX 5080、256²、64 views、3000 steps 的口径下报告：200k Gaussian 约 137 steps/s（约 22 秒）、120k triangle 约 280 steps/s（约 11 秒）、60k convex 约 77 steps/s（约 39 秒）。这些数字仅来自单卡、单分辨率和作者场景；不能外推到 AMD、Apple 或移动 GPU。当前限制包括 view-independent color（无 SH）、无 D-SSIM、Gaussian 上限 800k、triangle 400k、convex 250k，且导出尚未实现。评级 P1 研究原型，适合马上做交互和性能对照，不适合生产交付。

### Gaussian Splat to Blender Nodes：从观测到可审计 Blender 场景

[gokayfem/gaussian-splat-to-blender-nodes](https://github.com/gokayfem/gaussian-splat-to-blender-nodes) 在本窗口发布首批完整源码，许可 MIT。它将 splat 当作 reference observation，流程是：测量 frame/cameras → 拆分语义部件 → 生成 Geometry Nodes / Shader Nodes → 结构审计与可视对照 → 可选混合纹理映射 → 打包原生 .blend。

依赖为 Python 3.10+、Blender 5.0+（作者测试 5.0.1）。可通过 skills 安装命令、Claude plugin 或手工复制到 Codex 工作区使用。仓库包含有限 PLY/SPLAT/KSPLAT 元数据与 SHA-256 inspector、相机 manifest、audit scripts、Blender 渲染器、still/video 对照、synthetic starter，以及 prepare/project/assemble 的 hybrid mapping 工具。

必须明确边界：它没有通用 splat decoder/reference renderer，不自动做语义分割，也不附带原始 scan 或拟合好的 hybrid asset；审计脚本证明结构契约通过，不等于视觉已经相似。混合纹理得到的是捕获 radiance 或近似去光照材质，不是严格物理 albedo；几何或 UV 大改后需要重新 bake。相对普通导入插件，它的新增价值是可复查的重建过程，而不是“点击即网格”。评级 P1 可实际测试、早期工具链。

- **为什么**：这是静默改变训练输入的正确性修复，尤其影响项目迁移、批处理和无人值守训练。

### 2) Pryme8 Splat Lab

- **为什么**：它把 projection、sort、composite、backward、Adam 和 relocation 完整搬进 WebGPU，适合快速探索不同 splat primitive 与浏览器端私有训练。
- **门槛**：桌面 Chrome/Edge WebGPU；无需 CUDA、Python 或编译。先用在线 demo，再 clone 静态站。
- **测试**：同一 mesh/point cloud 分别训练 Gaussian、triangle、convex；记录 100k/200k primitive 下 steps/s、GPU memory、loss、画质和 reset；用 NVIDIA/AMD/Apple 各一台做矩阵。
- **预期收益**：把小规模实验部署门槛降到浏览器；当前最大风险是无 SH/D-SSIM、无导出、单作者 benchmark。

### 3) Gaussian Splat to Blender Nodes

- **为什么**：它不是另一个只会显示 PLY 的插件，而是把参考观测、相机、参数化部件、节点材质、审计和对照渲染串成可复查的 DCC 流程。
- **门槛**：Python 3.10+、Blender 5.0+；准备 splat reference、相机/测量信息和一个小场景。MIT。
- **测试**：先跑 synthetic starter，再做一组家具或房间部件；检查尺寸、相机、node graph、still/video 对照、hybrid mapping 与打包 .blend；不要用复杂自然场景作为首测。
- **预期收益**：让 splat 参考更容易转成可编辑、可交付的结构化资产；风险是语义拆分和建模仍需 agent/人工判断，不是自动重建。
