## Bubo² 准备推出云端高斯服务

Bubo² 介绍了从照片、视频和原始 Insta360 .insv 重建高斯，并在浏览器编辑和嵌入网页的服务。报道描述的是准备推出的产品，实际开放时间、收费和输入限制需要以服务上线状态为准。

事件报道日期：2026-11-11；补收日期：2026-11-13。

## ArcGIS 可对高斯做可视域与阴影分析

ArcGIS Maps SDK for JavaScript 5.2 为高斯图层增加可视域和阴影投射分析，让用户判断从某个位置能看见什么及光照遮挡。Esri 同时提醒，高斯伪影可能进入分析结果，外观完整并不保证几何分析准确。

事件报道日期：2026-11-11；补收日期：2026-11-13。

## SpAItial 向所有开发者账户开放 Echo-3 API

Echo-3 API 从企业专用扩大到所有开发者账户，可将手机帧及相机信息送入云端生成带尺度场景。开放权限不等于免费使用：每个任务存在基础积分和按帧计费，免费额度也可能不足以发起一次任务。

事件报道日期：2026-11-11；补收日期：2026-11-13。

## Spaghetti Splatting 用曲线替代独立高斯点

Spaghetti Splatting 将表示组织为相连曲线，既尝试保持一般场景的重建能力，也输出适合模拟的线状结构。它为毛发等连续结构提供新思路；论文结果不意味着现有播放器已能直接读取这种表示。

事件报道日期：2026-11-11；补收日期：2026-11-13。

## SplatPilot 将 Blender 场景训练成高斯

SplatPilot 3.0.1 在 Blender 5.3 中安排相机，用 Cycles 或 EEVEE 渲染训练画面，再在 Vulkan GPU 上训练并导出 PLY、SOG、SPZ。输入可以是已有虚拟资产，训练得到的是所选视角和光照下的表现。

事件报道日期：2026-11-11；补收日期：2026-11-13。

## Unreal Engine 5.9 预览版加入实验性高斯入口

Epic 在 5.9 MegaJam Preview 路线图中列出实验性高斯导入，支持将 PLY、SPZ 放入场景并结合 Niagara。创作者可以开始测试原生入口，但预览版不等同于正式生产支持，现有项目应使用副本验证。

## Splatmania 提供带剪辑时间线的浏览器编辑

design4real 的 Splatmania 基于 SuperSplat，增加多相机切换时间线、深度选择和立体全景输出。它面向在浏览器里整理扫描与镜头。部分公开代码入口本次返回 404，因此不将免费网页工具直接称为已经核实可自托管的开源项目。

事件报道日期：2026-11-11；补收日期：2026-11-13。
