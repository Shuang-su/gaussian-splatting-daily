## MipMap Desktop 增加行走与尺度校准

MipMap Desktop 3.3 加入行走模式、尺度标定和地理坐标测量，也可通过 API key 上传到 SuperSplat。它让扫描交付更接近可浏览现场；发布前需确认密钥与内容权限，测量仍依赖校准质量。

事件报道日期：2026-11-06；补收日期：2026-11-13。

## StarLightGS 使用 Unreal 灯光重照高斯

StarLightGS 是面向 Unreal Engine 5.7 及更新版本的开源插件，把高斯写入引擎的几何缓冲以接受现有灯光。它为实时重光照提供一条实现路径，真实材质恢复与原扫描阴影的处理仍需单独检查。

事件报道日期：2026-11-06；补收日期：2026-11-13。
