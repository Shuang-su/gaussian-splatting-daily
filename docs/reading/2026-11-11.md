## SuperSplat Viewer 1.43.0 扩大直接加载的格式

新版查看器可直接读 LCC2 与 SPZ，并调整 Firefox 上的 WebGPU 节流。发布前可用同一场景比较 Chromium 与 Firefox 的首帧和交互响应。

浏览器节流回归需要同时关注响应和资源使用，单次成功加载无法覆盖两者。

[来源](https://github.com/playcanvas/supersplat-viewer/tree/v1.43.0)

## SplatTransform 3.11.1 连接 GLB、压缩 PLY 与 SOG v3

新版本增加 GLB 高斯输入，并改善超大压缩 PLY 处理和 SOG v3 HTML 输出。实际交付宜用含球谐与透明度的代表性文件做转换和回读。

可打开文件和能保留所需属性是两项独立检查。

[来源](https://github.com/playcanvas/splat-transform/tree/v3.11.1)

## ArcGIS 可对高斯做可视域与阴影分析

ArcGIS Maps SDK for JavaScript 5.2 为高斯图层增加可视域和阴影投射分析，让用户判断从某个位置能看见什么及光照遮挡。Esri 同时提醒，高斯伪影可能进入分析结果，外观完整并不保证几何分析准确。

[报道与来源](https://radiancefields.com/esri-adds-viewshed-and-shadow-cast-analysis-to-splats) · [原始材料](https://www.esri.com/arcgis-blog/products/js-api-arcgis/announcements/arcgis-maps-sdk-for-javascript-whats-new-in-5-2)

## SpAItial 向所有开发者账户开放 Echo-3 API

Echo-3 API 从企业专用扩大到所有开发者账户，可将手机帧及相机信息送入云端生成带尺度场景。开放权限不等于免费使用：每个任务存在基础积分和按帧计费，免费额度也可能不足以发起一次任务。

[报道与来源](https://radiancefields.com/spaitial-echo-3-api-opens-to-every-developer-account) · [原始材料](https://github.com/spaitial-ai/spaitial-capture-prototype)

## Unreal Engine 5.9 预览版加入实验性高斯入口

Epic 在 5.9 MegaJam Preview 路线图中列出实验性高斯导入，支持将 PLY、SPZ 放入场景并结合 Niagara。创作者可以开始测试原生入口，但预览版不等同于正式生产支持，现有项目应使用副本验证。

## SuperSplat WebMCP 从文本控制走向可视反馈与实例化场景编辑

32 个 WebMCP 工具中增加 `render_view`、`instance_layer`、`create_from_generator`。`render_view` 可离屏输出最多四视图的 color / selection / property / layers / shaded JPEG/PNG；`instance_layer` 允许最多 128 个共享静态 Gaussian 数据的变换实例；generator 在无网络 CSP 沙箱内运行，限制 10 秒、200 万 Gaussian、64 列。

:::details[发布内容与使用条件]

- **时间 / 一手来源**：2026-11-10；[PR #1095](https://github.com/playcanvas/supersplat/pull/1095)，commit [`89fb456`](https://github.com/playcanvas/supersplat/commit/89fb456f76f24961c5d99affcc6baedf56be40ba)。
- **新增**：32 个 WebMCP 工具中增加 `render_view`、`instance_layer`、`create_from_generator`。`render_view` 可离屏输出最多四视图的 color / selection / property / layers / shaded JPEG/PNG；`instance_layer` 允许最多 128 个共享静态 Gaussian 数据的变换实例；generator 在无网络 CSP 沙箱内运行，限制 10 秒、200 万 Gaussian、64 列。
- **架构 / 影响**：代理现在可执行“修改→渲染→视觉核验”，而不是只读场景状态；实例层避免复制 splat payload，适合场景布置与重复资产。它不等同于新的 Publish API，也不改变 SOG/SPZ/PLY 编码。
- **可运行性**：可实际测试；MIT；WebGPU 浏览器；**可信度 B**。建议先用于非破坏式编辑与截图验收，再逐步开放写操作。

:::

[原始发布](https://github.com/playcanvas/supersplat/pull/1095)

## SuperSplat 修复极端 far plane 的 GPU 排序碎裂，并把训练滤波信息贯通到 Editor

透视排序键改为对数间距，避免少数离群 splat 把 far plane 拉大后中近景深度精度崩坏；Editor 新增抗锯齿 Auto/On/Off，使用 0.1 px² training filter 与 opacity compensation，并把 model tag 在 PLY/SOG/SPZ 间 round-trip。

:::details[发布内容与使用条件]

- **来源**：[PR #1097](https://github.com/playcanvas/supersplat/pull/1097)，commit [`1522a44`](https://github.com/playcanvas/supersplat/commit/1522a440c3c0bd0c39cb9c42db3382c191795687)。
- **新增**：透视排序键改为对数间距，避免少数离群 splat 把 far plane 拉大后中近景深度精度崩坏；Editor 新增抗锯齿 Auto/On/Off，使用 0.1 px² training filter 与 opacity compensation，并把 model tag 在 PLY/SOG/SPZ 间 round-trip。
- **性能 / 质量口径**：作者测试中错误红像素从约 18–24 万降为 0；这是确定性正确性样例，不是通用 FPS benchmark。
- **实际影响**：对大尺度扫描、飞散点与远距离背景最直接；AA tag 能避免已训练滤波场景重复补偿。**建议立即升级实验分支**，但 HTML 输出需同时使用 SplatTransform 3.11.1 才能完整保留 tag。
- **可信度 B**；另有 [PR #1096](https://github.com/playcanvas/supersplat/pull/1096) 把 `render_view` 的 frame wait 改为 5 秒可取消、播放时间线时拒绝渲染，并按请求相机重算分析范围，43/43 测试通过。

:::

[原始发布](https://github.com/playcanvas/supersplat/pull/1097)

## LichtFeld Studio 将外部训练结果从只读预览提升为完整可编辑模型

已完成/最佳训练结果可在 path confinement、regular-file、expected-size、SHA-256 与取消检查后，作为独立、全质量、可编辑模型导入；复用异步 loader、SH 验证、raw data 和 atomic scene transaction，允许重复导入。

## GPU 高斯渲染研究尝试拆分重图块

方法优先调度代价高的图块，将极端图块分配给多个计算块。作者报告大城市场景的加速，当期尚无代码和完整独立核验。

[论文](https://arxiv.org/abs/2611.12319)

## DPGS-SLAM 将生成内容和真实观测分开

方法为遮挡补全生成的高斯保留来源标签，使其不进入定位和真实地图优化。真实观测到达时删除相应生成内容，代码仓库当期为空。

[论文](https://arxiv.org/abs/2611.12038)

## RefineSplat 将物体轨迹转成独立高斯资产

方法结合开放词汇物体轨迹与多视图特征，重建可独立编辑和查询的物体。论文当期未公开实现。

[论文](https://arxiv.org/abs/2611.10379)

## SHIN 用基础层与增强层分配高斯质量

方法让多级质量共享高斯顺序，再分配新增基元与球谐预算。当前未提供可直接接入查看器的随机访问格式或下载。

[论文](https://arxiv.org/abs/2611.10652)

## PLS-GS 用 LiDAR 表面约束高斯地图

方法用相机和 LiDAR 的概率表面框架约束高斯贴近实测表面。项目页存在，代码和权重当期仍待发布。

[论文](https://arxiv.org/abs/2611.10699)
