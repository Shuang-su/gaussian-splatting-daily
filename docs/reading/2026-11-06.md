## SuperSplat Viewer 修复 Quest XR 黑屏和近裁剪

Viewer 1.42.1 处理 Quest XR 黑屏与大场景近裁剪。回归时应在真实头显中分别验证进入 XR、近处几何和大尺度场景。

这是发行版本。日报未执行物理设备验收。

[来源](https://github.com/playcanvas/supersplat-viewer/commit/a66496e647c58f34bdded4e104adbe4ac52fc423)

## PlayCanvas 提醒在 11 月 19 日前轮换旧 API token

11 月 5 日前创建的个人 API token 需要在 11 月 19 日前重新生成。使用 PlayCanvas 自动化发布或资产脚本的团队应核对凭据来源，并在替换后验证必要的请求和权限。

这是当期记录中的迁移日期，应结合所链接的官方通知判断部署环境的适用范围。

[来源](https://forum.playcanvas.com/t/api-tokens-generate-a-new-one-by-19-november/42758)

## Insta360 举办 Spatial Capture 创作挑战

Insta360 邀请 X5、X6 用户提交 Spatial Capture 高斯作品，报道给出的截止日期为 12 月 20 日。活动为普通用户提供展示和创作目标；报名资格、奖项和素材授权应以官方活动页为准。

[报道与来源](https://radiancefields.com/insta360-launches-a-spatial-capture-challenge) · [原始材料](https://youtu.be/ZzcXRoycB5M)

## MipMap Desktop 增加行走与尺度校准

MipMap Desktop 3.3 加入行走模式、尺度标定和地理坐标测量，也可通过 API key 上传到 SuperSplat。它让扫描交付更接近可浏览现场；发布前需确认密钥与内容权限，测量仍依赖校准质量。

[报道与来源](https://radiancefields.com/mipmap-makes-gaussian-splats-walkable-in-desktop-3.3) · [原始材料](https://na.mipmap3d.com/blogs/mipmap-desktop-3-3-new-tools-for-gaussian-splatting-measurement-and-sharing/)

## StarLightGS 使用 Unreal 灯光重照高斯

StarLightGS 是面向 Unreal Engine 5.7 及更新版本的开源插件，把高斯写入引擎的几何缓冲以接受现有灯光。它为实时重光照提供一条实现路径，真实材质恢复与原扫描阴影的处理仍需单独检查。

[报道与来源](https://radiancefields.com/starlightgs-relights-gaussian-splats-inside-unreal-engine) · [原始材料](https://github.com/CoSTAR-National-Lab/starlightgs-training)

## BudgetSplat 在推理时调节高斯数量

同一个前馈模型可以用保留比例适配多档高斯预算，避免为每档重新训练。当前只有论文，实际内存、速度和画质需要公开实现后比较。

[论文](https://arxiv.org/abs/2611.06593)

## OccSplat 在三维空间补全驾驶场景遮挡

方法定位环视图像中缺少支持的区域，直接生成高斯基元以补全遮挡。作者在 nuScenes 上报告效果，代码、权重与实时吞吐尚未公开。

[论文](https://arxiv.org/abs/2611.06273)
