## SOG v3 将旋转数据移到独立纹理

新版读取器从独立的 quats.webp 读取旋转，解决 WebKit 与 WebGPU 解码预乘会损坏原 alpha 通道旋转数据的问题。SplatTransform 3.11.0 和 3.11.1 生成的过渡 v3 需要从原始资产重转。

配套版本为 Engine 2.24.1、Viewer 1.43.2 与 SplatTransform 3.11.2。SOG v2 不受影响。维护者验证了 Chromium，Safari 仍需实机复核。

[来源](https://github.com/playcanvas/engine/pull/10007)

## SuperSplat 3.8.1 修正 3.8.0 的不透明度处理

3.8.0 将已经是线性的不透明度当成 logit，导致低不透明度高斯变得过实，表现为漂浮伪影或雾。3.8.1 修正显示、调整与导出。

维护者用 PLY 和降采样 SOG v3 检查了不同渲染模式。原生抗锯齿训练场景和最低不透明度筛选仍需项目方回归。

[来源](https://github.com/playcanvas/supersplat/pull/1103)

## LichtFeld 主干增加逐相机位姿优化

新选项可在 FastGS 针孔路径中联合优化相机位姿，默认关闭。畸变数据需要去畸变，GUT 路径暂不支持。

[来源](https://github.com/MrNeRF/LichtFeld-Studio/pull/4048)
