## LichtFeld 提前启动大数据集训练

LichtFeld 将大数据集的图片准备改为延迟处理，并限制预取量，让训练可以在全部图片准备完成之前开始。

作者在包含 3,686 张图片的 Pier90 数据集上，将首个训练进度出现前的等待从约 25 秒缩短到 14 秒。这说明启动阶段得到改善，不能直接换算为完整训练耗时同比下降；总时间仍受解码、数据读取与 GPU 计算影响。

[来源](https://github.com/MrNeRF/LichtFeld-Studio/pull/2253)

## Spirula Studio v2026.9.20 正式发布

Spirula Studio 发布 v2026.9.20，包含自适应视频抽帧、360 度相机组的运动恢复、批处理和 GPU 选择等更新。此前的 PLY 初始化训练也进入了二进制发行版。

版本同时修复 HDR、RGBA 和大模型网格提取相关问题。需要稳定复现环境的用户可以按这个发行版本记录依赖；其后主分支继续开发的功能应另行标注。

[来源](https://github.com/harry7557558/spirula-studio/releases/tag/v2026.9.20)

## Spirula 开发选择、删除与 MCP GUI 自动化

Spirula 正在增加高斯、稀疏点和网格的选择与删除能力，并扩展通过 MCP 操作界面和截图的自动化接口。

矩形、套索、画笔与连通区域等选择方式面向不同清理任务。这些内容属于发行版之后的开发进展，当期不能视为已经包含在 v2026.9.20 中。

## LichtFeld 减少缩略图更新时的工程文件写入

LichtFeld 调整工程文件的缩略图更新方式，使用追加数据减少对整个工程的重写。

作者在一个 646 MB、约 100 万高斯的工程中记录到约 220 KB 的追加量和 0.19 秒耗时。该数据对应缩略图更新，不代表所有工程保存操作；仍应检查中断恢复和工程重新打开是否正常。

[来源](https://github.com/MrNeRF/LichtFeld-Studio/pull/2254)

## LichtFeld 支持原生 Wayland 窗口

LichtFeld 补充 Wayland 所需的 Vulkan 窗口表面扩展，修复纯 Wayland 环境中的窗口启动问题。它主要影响 Linux 桌面兼容性，不改变训练算法。

[来源](https://github.com/MrNeRF/LichtFeld-Studio/commit/9ea981b2dbd474b43446d471551d5d0f61032bae)

## Framestore 将介绍 Superman 的 4DGS 制作流程

Framestore 将介绍《Superman》的 4D 高斯制作流程，涉及大规模相机采集和影视生产。本期记录的是活动预告，实际内容应以之后的演讲或公开资料为准。

[来源](https://london.siggraph.org/events/framestore-september)

## Polycam 发布 SuperSplat 到 UE5 的工作流教程

Polycam 发布从 SuperSplat 到 Unreal Engine 5 的工作流教程，展示扫描资产如何经过编辑再进入引擎。它提供实践路径，不能据此推断出现了新的重建算法或格式标准。

[来源](https://prod.framestore.com/work/superman)
