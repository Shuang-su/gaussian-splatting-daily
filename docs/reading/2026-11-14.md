## SuperSplat 开始编排动态高斯

SuperSplat 首次把 GSAF 动态高斯作为时间线序列导入，并能同时播放多段序列。它把动态资产从单独播放器带进编辑与视频输出流程，但目前只是主干合并，仍有系统拖放、最终视频和 PWA 文件关联等未测边界。

用户可以通过拖放、文件选择器、最近导入和 URL 参数打开 `.gsaf`，选择保留为序列或拆成独立帧。较短序列会停在末帧，播放途中加入的序列从当前播放头开始。视频导出也会在帧变化后重新排序，修正 360° 导出错帧的竞态。

[功能与测试边界](https://github.com/playcanvas/supersplat/pull/1108)

## LichtFeld 把裁剪变成可撤销的编辑状态

LichtFeld 将裁剪从立即删除改为可开关、可撤销、可延后烘焙的编辑状态，适合反复调整扫描边界和生成多个交付范围。当前范围是单个 splat 对象，组与混合选择尚不支持。

盒体、椭球和多边形裁剪可以叠加，也可以反转为排除区域。只有用户执行 Bake 后，点才被永久删除。维护者完整测试的是 Windows、CUDA 12.8 和 RTX 5060 Ti；Linux 尚缺等价的全应用 GPU 验证。

[实现与平台测试](https://github.com/MrNeRF/LichtFeld-Studio/pull/3886)

## LichtFeld 用文字生成对象遮罩候选

文本类别检测现在可以为 SAM 2.1 提供候选遮罩，减少逐帧点选。系统仍要求人工确认，而且只在当前帧重新检测；误检、目标重现和 CUDA 依赖是实际采用前必须验证的边界。

这条路径使用原生 CUDA 算子，不需要 Torch 或 ONNX Runtime。模型下载后会校验 SHA-256。它适合把“人物”“车辆”等英文描述变成初始候选，但不能替代人工审核，也不会在目标消失又出现时自动重新发现。

[功能与限制](https://github.com/MrNeRF/LichtFeld-Studio/pull/4057)

## Leica MANTIS 同步采集镜头、深度与相机运动

Leica MANTIS 在拍摄过程中同步采集场景几何和相机运动，试图把影视现场的数据准备前移。它计划 2027 年第一季度出货，价格、精度、支持机型和现场基准尚未公开，现阶段只能按产品发布而非交付能力评估。

配套软件计划输出 LiDAR 修正深度、相机轨迹、位置数据和点云，格式包括 EXR、FBX 与 Alembic。它不是高斯训练器，但输出可能直接进入重建、合成和空间内容管线。

[官方发布](https://hexagon.com/about/news-media/press-releases/2026/hexagon-launches-mantis-to-capture-3d-scene-data-as-cameras-roll)

## MatrixSplat 用 Tensor Core 加速高维特征渲染

MatrixSplat 把高维 Gaussian 特征贡献组织为 Tensor Core 矩阵运算，并以顺序无关加权换取并行性。作者报告的倍数来自特定数据集、通道数和 GPU 条件；没有公开代码时，不能把 kernel 加速直接写成普通 RGB viewer 的整体帧率。

这条路线更直接影响语言高斯、开放词汇语义和中间特征渲染。复现时需要固定通道数、分辨率、Gaussian 数和质量指标，并区分 kernel 时间与端到端帧时间。

[论文原文](https://arxiv.org/abs/2611.15153)

## SuperSplat 批量导入不再被无关文件拖垮

多文件导入现在会先识别 PLY 序列、SOG、LCC、项目文件及其配套文件，夹杂一份不支持的文件不会让整批失败。真实操作系统拖放以及 SOG、LCC 的完整审阅路径仍待补测。

[合并记录](https://github.com/playcanvas/supersplat/pull/1107)

## PlayCanvas 修复设备恢复后的高斯阴影

WebGL2 或 WebGPU 图形设备丢失后，GPU sort 会重传必要数据，CPU sort 会重新应用最后一次排序，避免恢复首帧把高斯阴影缓存成白色。代价是 CPU 路径会保留一份排序大小的缓冲。

[合并记录](https://github.com/playcanvas/engine/pull/10021)

## Viewer 把注释创作上限提高到 50

SuperSplat Viewer 的导出校验现在允许 50 条注释。播放端原本就能显示超过 25 条，因此这不是渲染器扩容，而是创作端限制放宽；标题和正文长度上限没有变化。

[合并记录](https://github.com/playcanvas/supersplat-viewer/pull/366)

## LichtFeld 缩短部分 SOG 球谐导出

LichtFeld 以 e-means 替换高阶球谐调色板的 k-means。作者在 RTX 4090 与 4 个场景上报告 SH1、SH2 导出明显缩短，但 SH3 基本不变；图像编码成为新瓶颈，不能概括成所有 SOG 导出都更快。

[实现与作者基准](https://github.com/MrNeRF/LichtFeld-Studio/pull/4061)

## Niantic 展示不依赖专门扫描的城市级定位

Niantic Spatial 把地面相机画面与卫星图和数字地图匹配，返回带不确定度的位置和朝向候选，并可与 SLAM、IMU 或里程计融合。当前公开的是定位能力，不是直接返回完整三维重建。

[官方说明](https://www.nianticspatial.com/blog/physical-ai-in-its-place)

## Prevu3D 为高斯资产加入轮廓显示

Prevu3D 的 2026 更新记录写明 Gaussian splat 可以显示轮廓，RealityComposer 中的资产也在范围内。官方没有同时给出独立版本号、性能数据或价格变化，本期仅按发布说明记录。

[发布记录](https://doc.prevu3d.com/en/release-notes/2026/)

## TopoEgo 表示 4D 场景中的分裂与融合

TopoEgo 用部件级刚体运动和随时间变化的 Gaussian 激活状态表示断开、合并、打开和关闭，处理连续形变场难以表达的拓扑变化。项目页写明代码与数据将公开，但本次核查仍是论文无代码。

[论文原文](https://arxiv.org/abs/2611.16012) · [项目页](https://topoego.github.io/)

## ReCan-GS 分离稳定场景与视角相关干扰

ReCan-GS 通过形变敏感度区分跨视角一致的核心与每个视角的干扰 Gaussian，目标是无需外部分割器或人工遮罩地去除遮挡、反射、烟雾和薄雾。当前未找到官方代码或权重。

[论文原文](https://arxiv.org/abs/2611.16259)

## Kosmo-GFM 组织几何预测与位姿优化

Kosmo-GFM 把相机、深度、对应关系和动态点预测，与后续位姿及几何优化组织成一条重建管线。论文给出 34 个场景的累计耗时，但这是作者汇总，不是第三方生产评测；当前也没有公开实现可供复核。

[论文原文](https://arxiv.org/abs/2611.16840)

## ThermalSplat 面向无 RGB 的稀疏热成像重建

ThermalSplat 从稀疏热红外图像前馈生成 Gaussian，不要求 RGB、已知相机位姿或逐场景优化。它针对热成像低纹理与强度差异设计损失，但当前未找到代码、权重或独立设备测试。

[论文原文](https://arxiv.org/abs/2611.15435)
