## 阶段 3：RSS、周汇总与完整验收

实现 checkpoint：`cec81fd2a202dff46b8687f0ea1e4272d05ba27a`。完成记录另作本地文档提交；交付产物中的 `deployment.json` 登记最终 HEAD，完整 SHA 在 Codex 交付中列明。

`site/lib/feeds.ts` 从规范 Markdown 派生的归档生成每日 RSS 和周汇总模型。每日保留最近 60 期，包含完整短摘要、网页实际展示的“今日最值得看”和全文链接。周汇总按北京时间的报告日期、ISO 周年份及周一至周日分组；最新完整日报所在周保持开放。进入下一周的首期完整日报关闭上一周。网页和 RSS 使用同一个 `WeeklyDigest`，事件按日期逆序并以稳定 ID 去重。

本次产物有 13 条每日记录和 2 条周记录：2026 年第 38 周覆盖 9 月 18—20 日的 3 期，第 39 周覆盖 9 月 21—27 日的 7 期。第 40 周没有生成汇总。周页同时列出自然周和实际归档覆盖日期、期数。

新增 `/subscribe/`、`/feeds/daily.xml`、`/feeds/weekly.xml` 与 `/weekly/YYYY/WW/`，统一带 `/gaussian-splatting-daily` 前缀。导航、首页侧栏、文章结尾和页脚可进入订阅页。两个复制按钮经浏览器读取确认得到正式 HTTPS 地址；“打开 RSS”使用当前预览路径。HTML 注册每日及每周订阅源。

最终阅读验收修复了三个问题：

- 返回首页时，已加载 12 条内容会先被初始 6 条的页长限制滚动位置。等待恢复后的列表渲染完成再恢复阅读位置，实际返回保持在原来的 1512.5px。
- 长标题中的空白区域可能没有命中换行后的内联链接。标题链接改为块级区域；事件锚点只保留一次 76px 顶栏偏移。Spirula 与 Mobile-4DGS 分别定位到各自介绍段落，完整目录仍为 13 栏。
- 缩略图失败缺少直接来源入口，且静态 HTML 图片请求可能早于 React 绑定 `onError` 失败。图片链接移到正常图片内部，失败区提供独立来源链接，并在脚本挂载时检查已失败图片。104px 缩略图采用较小内边距，实测来源链接完全位于裁切范围内，没有嵌套链接。
