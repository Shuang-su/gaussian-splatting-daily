## 3. RSS、订阅入口与内容接口

新增以下静态入口，统一带项目路径前缀 `/gaussian-splatting-daily`：

- `/subscribe/`：提供“每日简报”和“每周汇总”，支持复制订阅链接与打开 RSS 文件。
- `/feeds/daily.xml`：每期日报一条，包含标题、短摘要、今日最值得看和全文链接，保留最近 60 期。
- `/feeds/weekly.xml`：每个已结束的自然周一条，保留最近 26 周。
- `/weekly/YYYY/WW/`：周汇总的静态阅读页，供每周 RSS 链接进入。

周汇总按北京时间、周一至周日分组。以最新完整日报的日期判断已经结束的周，在跨入下一周的首期构建中生成上一周汇总。逐日列出已有日报标题、摘要和全文链接，并汇总现有 highlights，按日期逆序排列、按稳定标识去重。历史不足七期或中途缺期时，显示实际覆盖日期与期数。

页面与 RSS 复用同一个派生周汇总模型；规范 Markdown 继续作为唯一正文来源。既有 schema v1、`source_count` 含义、论文 marker 和工具标识保持兼容。RSS 使用稳定 GUID，纠错更新同一条目；所有链接使用包含项目前缀的绝对地址，并在 HTML 注册订阅源发现入口。[RSS 2.0 规范](https://www.rssboard.org/rss-specification)

导航、首页列表侧栏和文章结尾提供订阅入口，文案采用“订阅高斯日报”“每日简报”“每周汇总”。本轮入口直接对应可用的 RSS 功能。

后续若加入邮件，需要再选择发送服务和发布方式。Substack 官方表单可以嵌入网站，但目前不能自定义外观，因此暂不将其作为本轮实现依赖。[Substack 官方说明](https://support.substack.com/hc/en-us/articles/360041759232-Can-I-embed-a-signup-form-for-my-Substack-publication)

## 4. 验证标准

- **视觉与响应式：**检查 375、390、430、768、1024、1440px；覆盖三种外观。保存桌面、手机首页、列表、日报正文、订阅页和暗色模式截图。参考站对照使用相同采集内容、视口和轮播状态。
- **连续操作：**验证手机早报轮播卡片恢复、桌面与手机切换、菜单、目录跳转、返回列表、加载更多、搜索、图片预览及焦点恢复。布局变化不得重置阅读和筛选状态。
- **内容兼容：**核对 13 期日报、9 月 18 日增量、论文 marker、来源计数、旧栏目锚点及同栏事件定位；正文与人工分析完整保留。
- **RSS：**验证 XML 转义、中文、绝对地址、项目前缀、稳定 GUID、重复构建、纠错、跨年周编号、缺期、部分周和未结束周。周汇总与网页读取同一份数据，导出链接检查覆盖 RSS 内部链接。
- **静态构建：**通过内容检查、现有 Python 与网站测试、TypeScript、Next.js 静态导出和链接检查；参考站修正通过其既有测试与构建。浏览器模拟与真实手机手势分别记录，未做设备测试的部分明确列出。

RSS 与网页放在同一部署产物中。部署失败时，公开网站和订阅源仍保持上一成功版本；本地构建通过不计作公开上线完成。
