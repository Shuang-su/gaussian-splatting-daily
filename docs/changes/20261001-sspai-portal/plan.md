# 高斯日报门户改版与本地验收：实施计划

采用 [request.md](request.md) 中完整的用户确认要求。本次实施目录为最新恢复包中的 `project/`；旧日报目录与 Metaflow 工作区不改动，Metaflow 标识只读复制。

1. 检查分支、upstream、工作树与恢复包逐文件校验；在 `codex/sspai-portal-refinement` 保存恢复版基线。保留原发布校验、checkpoint 和自动化状态。
2. 先实现 9 月 30 日阅读流程：原始品牌、真实封面、具体标题和摘要、编号导读与折叠目录、精确事件锚点、完整正文、来源纠错和往期链接。
3. 同一构建层推广至全部 13 日期及首页、日报、论文、工具、主题、搜索。Markdown 正文不改；元数据、索引和渲染层保持唯一来源。归档过程说明保留在文末，事实限制仍在对应正文。
4. 逐期查看官方素材，选择可准确归属的图片；保存原尺寸图片或官方演示帧，生成无放大的 WebP 与来源 manifest。无对应图的报道采用文字。生成使用原始标识的分享图。
5. 实现统一图片 key、加载失败、原图预览及 SVG 工具栏；检查实际尺寸、旋转、平移边界、切图、触控、键盘与焦点恢复。
6. 执行内容检查、Python/网站测试、TypeScript、静态构建和导出检查；在静态文件服务器验收全部页面、指定断点、主题持久化、搜索过滤、直接刷新、错误状态及内容 hash。
7. 保存截图与本地验收结果，建立改版提交和完成记录。仅交付本地预览和静态产物；公开发布、部署与真实定时观察按原计划后续执行。

媒体与浏览器产物暂存于项目 `.codex-work/`；采用的公开网站图片及来源记录属于改版提交，截图为本地交付。真实手机触控只在具备真实设备时登记，不以浏览器模拟替代。
