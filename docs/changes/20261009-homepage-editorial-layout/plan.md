# 首页改版实施计划

## 范围

重排首页及其导航。桌面顶部只保留居中大封面轮播，取消两侧顶部内容；下方保留栏目、文章列表和近期动态三栏。平板横屏沿用紧凑三栏，竖屏收起右栏、将左栏缩为图标加短标签。所有尺寸区间保留图片、独立标题面板与跨界日期牌；手机增加页头栏目下拉和全屏导航。

## 内容与交互

- 日报条目元信息为 Logo、Metaflow、日期、日报图标、高斯日报。
- 最近 5 期归档日报提供轮播；推荐混合列表选取日报和已归档配图的论文/工具、避免同日题图重复、按归档日期排序，日报、论文、工具各自有真实列表；日报列表包含最新一期。
- 不展示缺少数据来源的热门、关注、用户身份或评论计数。右栏明确称为近期动态。
- 桌面列宽与手机图片比例、字体、日期牌阴影以用户截图及实际参考页样式为依据；使用本站品牌与真实封面，不复制少数派品牌图案。
- 轮播支持自动播放、暂停、键盘选择、指针手势；焦点、悬停、后台与减少动态效果时暂停自动切换。
- 栏目选择及加载进度共用客户端状态，延续现有会话保存；断点切换不重建内容状态。
- 手机/平板菜单提供真实站内搜索、现有导航、外观选择；支持 Escape、焦点恢复与焦点限制。
- 保持静态导出、图片来源回退和文章锚点兼容。RSS 在构建中先保存并在静态导出前恢复原字节。

## 布局与验收

- 桌面 >=1024px：居中大卡片，上方封面、下方独立标题面板与跨界日历牌；下方三栏。
- 平板 768–1023px：中央封面/标题面板与跨界日历牌，左侧窄图标栏，单个主列表，收起右栏。
- 手机 <768px：16px 页边距，封面图片比例约 396/275.21，标题面板，50px 日期牌；页头栏目下拉，单列文章列表配右侧 4:3 缩略图。
- 日期牌在三个区间都保留 50px 尺寸、红色星期栏和独立数字底色/阴影。头图标题在桌面/平板为 24px，手机为 17px。
- 检查 375、390、430、550、768、820、1024、1180、1441px 及临界断点；覆盖浅色、暗色、跟随系统。记录实际浏览器宽高，避免把设备像素当作 CSS 宽度。
- 验证轮播、栏目切换、加载、跨断点状态、站内搜索、菜单键盘及文章链接；复核字体/图片裁切/留白/阴影。
- 运行定向网站测试、TypeScript、静态构建、内容/导出链接检查；保存对照截图、差异清单和实际未运行项。
- 本地 checkpoint 提交并报告 SHA、工作树状态和本地门户。不执行推送、PR、公开部署、RSS 改版或真实 GitHub 写入。

## 本轮尺寸与留白修订

- 图片容器完全填入已设比例的头图区域，避免原图的固有高度撑开卡片；原图文件和正文图片保持原有比例。
- 768–1023px：80px 图标栏从页面左缘开始，列表与图标栏相隔 44px，列表右侧也留 44px；820px 时列表起点 124px、宽度 652px。
- 1024–1279px：下方三栏为 164 / 520 / 164px，栏间距 56px，含左右 32px 留白的容器最大 1024px。1180px 时列表起点 330px。
- >=1280px：下方三栏为 200 / 588 / 200px，栏间距 106px，含左右留白的容器最大 1264px。头图宽度与列表宽度分别按各自展示规则处理。
- 在 375、390、430、550、767、768、820、1023、1024、1180、1279、1280、1440、1441px 下，逐张选择五期轮播，分别验收浅色与暗色，共 140 组。检查实际视口、封面区域比例、卡片高度、日历边界、列表位置、元信息换行和横向溢出。
- 对照本地冻结参考 CSS 与当前原站 DOM 坐标；记录首轮只测首张封面尺寸、未比较栏宽/留白的验收缺口。复核图片失败回退与恢复，重建静态产物并保持 RSS 字节不变。

## 侧栏与矮屏修订

- 按用户要求叠合截图。以阅读区分隔线校准滚动偏移后，分别检查栏目按钮内部的字号、图标、颜色、内边距和行间距；不把截图滚动偏移当成页面布局偏移。
- >=1280px 且高度 >900px：栏目字体 20px / 500、图标 32px、图文间距 8px，每项上下 16px；列表上下 16px，无额外条目 gap。首个图标和首条文章内容均距阅读区顶部 64px。
- 1024–1279px 或桌面高度 <=900px：栏目字体 17px / 500、图标 24px，行距 56px。矮屏使用 1024px 容器、164 / 520 / 164px 三栏及 56px 栏间距，头部卡片限制为 480px；保留封面与标题面板分割、跨界日期牌。首项距阅读区顶部 32px。
- 桌面头部卡片与参考断点一致：紧凑区间 480px，>=1280px 且高度 >900px 为 588px。替代按视口连续计算的旧规则，避免 1024px 视口下标题内容把 400px 卡片撑高。手机与竖屏平板头图继续沿用此前已确认的规则。
- 768–1023px：图标栏按钮宽 80px、内边距 16px、图标 32px、字号 11px / 400、图文间距 4px，无额外条目 gap；图标中心在左侧栏中线，首项距阅读区顶部 32px。80px 栏宽、44px 栏间距和列表右边距保持既定规则。
- 栏目选中、未选中和悬停颜色分别设置浅色与暗色变量；不改变文章正文或元信息的全局颜色。粘性侧栏停在 56px 页头下方。推荐图标改为圆角房屋轮廓，其他栏目保持本站语义。
- 用户继续指出工具图标问题。修正同一 Icon 组件中的扳手闭合路径、钳口圆角与手柄末端，复核 14、24、32px 的文章元信息、手机下拉和侧栏显示；不另加一套图标实现。
- 复核四个主要视口和宽高断点两侧，覆盖浅/暗色；检查手机栏目下拉、平板栏目键盘切换、加载进度和粘性侧栏。静态构建与内容检查后创建本地 checkpoint，不推送或部署。

## 工具图标来源与选型修订

- 核对 Icon 组件首次加入与首页扩展的 Git 历史、依赖和来源记录。区分本地手写路径、形状能与上游匹配的图标及少数派专有图标字体，不把全部现有图标称为同一官方图标库。
- 按现有 24×24 viewBox、单色线框、圆角端点/连接和本站 1.7px 描边筛选。对比旧扳手、新版 Lucide Wrench、Tabler Tools 和 Lucide Toolbox 与当前房屋/报纸/论文轮廓的协调性。
- 使用 Lucide 官方 Toolbox 路径，固定上游 commit，记录来源与原始 SHA-256，保留许可证。只替换共享 Icon 的 tool 分支，尺寸、颜色和布局沿用现有规则。
- 验收首页工具栏目切换、桌面 32/24px、平板 32px、手机菜单 24px、全屏导航及元信息 14/12px，覆盖浅暗色、选中/未选中；检查遮裁、横向溢出、页面身份和控制台。运行 TypeScript、Next 静态构建和导出校验，复核归档/索引/RSS 基线。

## 手机导航修订

- 复现 430×932 页头。当前菜单 SVG 中心 y=24.5，其他控件 y=27.5；用相同控件高度和 flex 居中修正。页头选择文字与 Logo 继续共用垂直中心，菜单打开时栏目下拉箭头隐藏并阻止误操作。
- 移动导航保持挂载，通过透明度与12px位移做展开/收起过渡。闭合时立即 inert/aria-hidden，展开时锁定背景并限制键盘焦点；在手机/平板/桌面断点切换时恢复桌面导航。减少动态效果时取消过渡。
- 外观采用「跟随系统 / 浅色 / 暗色」三段按钮，保留真实主题状态与持久化；键盘焦点可见。搜索输入采用整行底线焦点提示，避免自动焦点的矩形外框。
- 验证手机与平板尺寸、两种外观、动画实际中间状态与终态、减少动态效果、焦点循环/Escape/快速开关、真实导航与搜索、主题重载持久化、断点恢复、正文页面共享导航和桌面回归；运行TypeScript、构建、静态导出与内容/RSS基线核对。本地checkpoint，不推送或部署。

## 文章目录动画与固定

- 实际参考 `https://sspai.com/post/115532`：悬停时展开，文字透明度以360ms、cubic-bezier(0.5,0,0,1)过渡；图钉固定后移开仍显示，取消固定再移开则收起。冻结参考站也已有图钉，缺口在本地文章页移植。
- 桌面目录新增独立固定状态及可访问的图钉按钮。悬停为临时预览，固定后正文点击、滚动及章节跳转保持目录可见；收起按钮或Escape明确解除固定并关闭。固定仅保留当前文章会话，跨入紧凑尺寸时不自动打开遮罩，返回桌面可恢复固定状态。
- 目录持续挂载，闭合时立即inert/aria-hidden，使用透明度和轻微位移过渡；手机/平板为滑入弹层，遮罩同步淡入。减少动态效果时取消动画。沿用层级、活动标题、内部滚动、锚点与阅读位置保持。
- 图钉复用Icon组件，采用与Toolbox相同固定Lucide版本的原始路径与现有许可证，不新增依赖或修改上游冻结快照。
- 浏览器核验实际动画中间帧、悬停/图钉/正文点击/滚动/章节跳转/取消固定、Escape及焦点恢复；检查手机和平板的焦点循环、背景锁定与关闭，1279/1280断点、长子目录与减少动态效果。运行TypeScript、静态构建和导出/基线校验，保存本地截图和checkpoint，不修改内容或RSS。

## 目录运动复刻修正（替代桌面整块淡入/位移）

- 实际逐帧采集原站：同一组竖向标记收起为2×6px、条目高12px；展开条目立即33px，文字360ms淡入，标记容器10→33px，标记线立即21px；收起时文字高度立即回到12px并立即隐藏（透明度仍过渡），标记容器33→10px、标记线21→6px缓动，使整个目录围绕垂直中心压缩。正文和文字无水平位移。
- 用同一套链接行、prefix和text实现开放与收起，移除独立横线阵列与桌面8px位移。闭合链接继续inert/aria-hidden，透明按钮覆盖闭合标记区域承担悬停与键盘触发；图钉状态、Escape和真实章节跳转保持。
- 桌面目录围绕页头下方阅读区中线；页头控件和回到开头放在目录上下留白，避免改变条目收缩轨迹。手机/平板沿用已验收的弹层、位移、长标题换行与焦点行为。
- 对照原站/本地的逐帧行高、标记高、透明度与水平坐标；保存实际运动证据，检查终态、固定与取消固定、快速反转、减少动态效果、子目录、桌面/紧凑断点及手机回归。前轮34状态仅证明功能及淡入参数，不能作为几何运动一致的验收。

## 置顶按钮动画补齐

- 原站实际点击会平滑滚到scrollY=0，按钮保持显示，图标无额外位移；悬停颜色使用150ms、cubic-bezier(0,0,0,1)。冻结参考站已有window.scrollTo({top:0,behavior:'smooth'})，本地移植遗漏并沿用了章节跳转instant。
- 仅回到文章开头的两个入口使用浏览器原生smooth回顶，终点为页面顶部0；保留hash、可访问焦点和目录固定状态。其他章节跳转保持既有行为，减少动态效果时使用instant。
- 补齐右下角置顶入口的悬停颜色过渡，减少动态效果取消该过渡，不添加原站未显示的图标飞出或按钮进退动画。
- 对照原站与本地相同滚动距离的实际中间轨迹及终点，验证重复点击、用户滚动中断、键盘、目录内回顶、手机/平板目录关闭与滚动解锁、减少动态效果和正文目录回归。构建、导出与20个内容基线核对后本地checkpoint，不改变数据、RSS或公开站点。
