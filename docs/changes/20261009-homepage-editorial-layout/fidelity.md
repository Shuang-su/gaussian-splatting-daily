依据用户提供的桌面、平板和手机截图，以及少数派首页的实际 DOM/样式。2026-10-09 最后一条修订要求桌面、平板也保留分开的封面/标题面板与日历牌，优先于此前截图中通用文章的白字覆盖标题。

| 交互 | 栏目切换、加载更多、跨断点及生产页面重载恢复；轮播键盘/自动播放/暂停；下拉与全屏菜单焦点；真实 GET 搜索与返回 | 真实手机触摸与后台标签页暂停未运行实机验收 |

首轮检查的 CSS 宽度为 375、390、430、550、767、768、820、1023、1024、1180、1440、1441px，每个宽度分别检查浅色、暗色，共 24 组。尺寸记录只覆盖当时首张封面，没有证明其他四张卡片高度一致，也没有将平板栏宽和左右留白逐项与参考比较。用户批注后确认这是验收漏项。

## 尺寸与留白补验

本轮在上述宽度中加入 1279 / 1280px，逐张选择五期日报并检查两种外观，共 140 组。全部组内卡片高度、头图高度、日历位置和列表起点的差值均为 0；图片区域保持约 396 / 275.21 的比例，无横向溢出，日报元信息保持一行。430px 时阻断 ARKit 封面变体，失败回退仍在同一 396×275.20px 图片区域内，卡片保持 398px 高；解除阻断并重载后图片恢复，正常重载无控制台警告或错误。

| 视口 | 参考布局 | 修正后的高斯日报 | 首轮偏差 |
| --- | --- | --- | --- |
| 820px | 左栏 x=0、宽80；列表 x=124、宽652；两侧留白44 | 相同 | 左栏 x=16、宽64；列表 x=112、宽676；右侧32 |
| 1180px | 左栏 x=110、宽164；列表 x=330、宽520；右栏 x=906、宽164；间隔56 | 相同 | 列表 x=351、宽478；将头图宽度用于列表 |

本地参考站 `reference-sites/public/styles/sspai-home.css` 已包含 `.feed__main` 两侧 44px 的规则，旧记录也有 768 / 1024px 首页截图。平板间距没有在这次移植中正确沿用，不能归因为未采到参考内容；旧记录的页长与溢出检查也不能替代几何对照。本轮原站坐标通过实际生效的 CSS 视口读取，尺寸模拟与网络规则结束后恢复。
