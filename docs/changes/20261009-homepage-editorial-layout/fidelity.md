# 首页视觉对照与验收差异

依据用户提供的桌面、平板和手机截图，以及少数派首页的实际 DOM/样式。2026-10-09 用户此前修订要求桌面、平板也保留分开的封面/标题面板与日历牌，优先于截图中通用文章的白字覆盖标题。

| 维度 | 实际结果 | 差异或限制 |
| --- | --- | --- |
| 顶部几何 | 宽屏且高度 >900px 时卡片588px；1024–1279px 或桌面高度 <=900px 时480px；两侧顶部卡片已移除 | 后续断点复核替代此前1180px时478px的连续计算规则 |
| 日历与阴影 | 全部 24 个尺寸/外观组合显示 50×50px 日历，位于图片底边上方 18px；星期色 #DA282A，暗色数字底色 #39393C | 保留参考的两层阴影；使用本站日期与品牌 |
| 文字 | 首页使用系统字体栈；头图标题桌面/平板 24px，手机 17px；列表为 20px/34px 或 17px/24px | 标题最多两行；完整标题仍进入链接可访问名称与文章页 |
| 颜色 | 浅色白色页面/浅灰面板；暗色页面与面板分层；跟随系统的浅色/暗色模拟均验证 | 系统外观通过浏览器媒体模拟验证，未修改 macOS 设置 |
| 图片 | 使用归档真实封面，复用本地 WebP、原图身份及来源回退；正常页面未发现损坏图片 | 不复制少数派品牌插画；手机与桌面使用相同内容、不同裁切尺寸 |
| 留白与圆角 | 桌面卡片 24px 圆角、手机 20px；手机 16px 页边距；标题面板留出跨界日历的空间 | 375px时仍允许卡片略高于正方形；桌面两档已固定为480/588px正方形 |
| 下方布局 | 768–1023px 为从左缘开始的 80px 图标栏，列表左右 44px 留白；紧凑桌面三栏164 / 520 / 164px、间隔56px；宽屏且高度 >900px 为200 / 588 / 200px、间隔106px | 矮屏规则优先于宽屏宽度规则；右栏使用真实「近期动态」 |
| 元信息 | 日报为 Logo、Metaflow、日期、日报图标、高斯日报；375px 和紧凑桌面均保持一行 | 论文/工具保留 arXiv/GitHub 等真实来源 |
| 交互 | 栏目切换、加载更多、跨断点及生产页面重载恢复；轮播键盘/自动播放/暂停；下拉与全屏菜单焦点；真实 GET 搜索与返回 | 真实手机触摸与后台标签页暂停未运行实机验收 |

首轮检查的 CSS 宽度为 375、390、430、550、767、768、820、1023、1024、1180、1440、1441px，每个宽度分别检查浅色、暗色，共 24 组。尺寸记录只覆盖当时首张封面，没有证明其他四张卡片高度一致，也没有将平板栏宽和左右留白逐项与参考比较。用户批注后确认这是验收漏项。

本地截图与测量保存在 `.codex-work/references/homepage-editorial-layout/`，包括 `light-1441.png`、`light-1180.png`、`light-820.png`、`light-430.png`、对应暗色图、系统外观、手机下拉/导航和图片失败状态。原始参考截图保存在同一目录。该目录属于项目内忽略的验收输出，不进入产品素材或 RSS。

## 尺寸与留白补验

本轮在上述宽度中加入 1279 / 1280px，逐张选择五期日报并检查两种外观，共 140 组。全部组内卡片高度、头图高度、日历位置和列表起点的差值均为 0；图片区域保持约 396 / 275.21 的比例，无横向溢出，日报元信息保持一行。430px 时阻断 ARKit 封面变体，失败回退仍在同一 396×275.20px 图片区域内，卡片保持 398px 高；解除阻断并重载后图片恢复，正常重载无控制台警告或错误。

| 视口 | 参考布局 | 修正后的高斯日报 | 首轮偏差 |

本地参考站 `reference-sites/public/styles/sspai-home.css` 已包含 `.feed__main` 两侧 44px 的规则，旧记录也有 768 / 1024px 首页截图。平板间距没有在这次移植中正确沿用，不能归因为未采到参考内容；旧记录的页长与溢出检查也不能替代几何对照。本轮原站坐标通过实际生效的 CSS 视口读取，尺寸模拟与网络规则结束后恢复。
