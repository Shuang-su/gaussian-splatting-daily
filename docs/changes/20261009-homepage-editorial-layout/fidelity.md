# 首页视觉对照与验收差异

依据用户提供的桌面、平板和手机截图，以及少数派首页的实际 DOM/样式。2026-10-09 最后一条修订要求桌面、平板也保留分开的封面/标题面板与日历牌，优先于此前截图中通用文章的白字覆盖标题。

| 维度 | 实际结果 | 差异或限制 |
| --- | --- | --- |
| 顶部几何 | 1441px 时居中卡片 588px，x=426.5、y=88；1180px 时 478px；两侧顶部卡片已移除 | 卡片改为日报的图片/标题分割，遵循最后修订 |
| 日历与阴影 | 全部 24 个尺寸/外观组合显示 50×50px 日历，位于图片底边上方 18px；星期色 #DA282A，暗色数字底色 #39393C | 保留参考的两层阴影；使用本站日期与品牌 |
| 文字 | 首页使用系统字体栈；头图标题桌面/平板 24px，手机 17px；列表为 20px/34px 或 17px/24px | 标题最多两行；完整标题仍进入链接可访问名称与文章页 |
| 颜色 | 浅色白色页面/浅灰面板；暗色页面与面板分层；跟随系统的浅色/暗色模拟均验证 | 系统外观通过浏览器媒体模拟验证，未修改 macOS 设置 |
| 图片 | 使用归档真实封面，复用本地 WebP、原图身份及来源回退；正常页面未发现损坏图片 | 不复制少数派品牌插画；手机与桌面使用相同内容、不同裁切尺寸 |
| 留白与圆角 | 桌面卡片 24px 圆角、手机 20px；手机 16px 页边距；标题面板留出跨界日历的空间 | 375px 与 1024px 时允许卡片略高于正方形，以容纳标题和留白 |
| 下方布局 | 桌面/平板横屏三栏；768–1023px 为 64px 图标栏加主列表、隐藏右栏；手机单列配右缩略图 | 右栏使用真实「近期动态」，未添加缺少来源的热门排行 |
| 元信息 | 日报为 Logo、Metaflow、日期、日报图标、高斯日报；375px 和紧凑桌面均保持一行 | 论文/工具保留 arXiv/GitHub 等真实来源 |
| 交互 | 栏目切换、加载更多、跨断点及生产页面重载恢复；轮播键盘/自动播放/暂停；下拉与全屏菜单焦点；真实 GET 搜索与返回 | 真实手机触摸与后台标签页暂停未运行实机验收 |

检查的 CSS 宽度为 375、390、430、550、767、768、820、1023、1024、1180、1440、1441px。每个宽度分别检查浅色、暗色，共 24 组，均无横向溢出；每组日历牌显示、位置及元信息高度已记录。
