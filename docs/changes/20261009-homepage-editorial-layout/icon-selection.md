## 旧实现的实际来源证据

- `4b53bad` 首次加入 Icon 组件：6 个直接声明的 SVG 图形，没有图标库依赖或来源记录。
- `1676313` 加入首页房屋、报纸、论文、工具等 SVG 路径；仓库没有说明这些路径来自同一个官方图标集。因此不能把整个组件认定为某一套原版图标，也不能断言每个路径都是原创。
- `3b9df74` 的工具路径与 [Lucide 0.423.0 Wrench](https://github.com/lucide-icons/lucide/blob/0.423.0/icons/wrench.svg) 的几何相同，末尾显式直线由闭合 `Z` 替代。上一轮「重绘」的描述不准确：它实际使用了旧版现成路径，且没有补来源说明。
- 少数派本地参考站保存的是其页面图标字体；`reference-sites/NOTICE.md` 明确素材权利归属。这与高斯日报的 SVG 组件不是同一来源。

## 条件与结果

候选按 24×24 网格、单色线框、圆角端点与连接筛选，在本站 1.7px 描边下并排查看 32/24/14/12px，并与当前房屋、报纸和论文图标比较。新版 Wrench 保留圆头与斜长手柄，Tabler Tools 是尺与笔的交叉图形；本轮选择 Lucide Toolbox。工具箱轮廓较均衡，也适合工具集合这一栏目。这是实现作者的视觉判断，不是用户已经确认的偏好。

采用 [Lucide Toolbox 官方 SVG](https://github.com/lucide-icons/lucide/blob/a04f228cd01185e09c188b7227b9600c08c565ec/icons/toolbox.svg)，上游 commit `a04f228cd01185e09c188b7227b9600c08c565ec`。五条 path 原样采用，仅由现有 Icon 容器控制尺寸、颜色和 1.7px 描边，不安装额外图标包。

原始 SVG 的 SHA-256 为 `09f2caafe0c478a0c26aad2d75c4c106ba8300fdfda6f4209fb097aeac115d04`。完整上游许可保存于 `site/public/licenses/lucide.txt`，随静态站导出，许可证 SHA-256 为 `b495047bd93a9b06913511076f504daba17d5bbeb3e0650f3bb53a4220329c57`。候选 SVG、下载来源及本地视觉对照保存在 `.codex-work/downloads/tool-icons-20261009/` 和 `.codex-work/references/tool-icon-selection-20261009/`。
