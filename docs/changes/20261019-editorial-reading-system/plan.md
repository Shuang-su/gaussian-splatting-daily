# 最终执行计划

## 目标

根据指定少数派规范、编辑器与文章，以及最近 30 篇派早报，建立适合高斯日报的写作规则，优化现有阅读版并将论文、工具、周报和专题纳入相同阅读体系。同时兼顾快速了解动态、判断工作流和深入复现三种阅读需求。

## 第一阶段：研究、规则与日报

1. 读取 5 个用户指定入口，并从派早报栏目按实际顺序读取最近 30 篇；记录样本、来源、范围、例外与方法，区分平台政策、文章经验和本项目决定。
2. 检查实际预览仓库、分支、上游、脏文件及历史内容；在隔离分支实施，保护既有卡片动画与其他工作。
3. 保留研究原文，以绑定 SHA-256 的阅读版重写导语、标题、段落和层次。将可读正文与可展开深读结合；关键条件、许可及发布状态不折叠隐藏。旧锚点、论文首次归档身份、来源与 RSS GUID 保持稳定。
4. 覆盖 2026-09-18 至 2026-10-18 的 31 期。既有 16 期原文不变；从固定上游提交导入 10 月 4–18 日的 15 期原始字节，再编写阅读版。
5. 统一正文行宽、段距、标题层级、表格和代码溢出、配图与图注。图片放在相关段落后；缺乏合适证据时不强行补图。选择与当期项目对应的封面；按用户实施中修正，页面使用简洁图注和来源，历史版本核验记录留在仓库，不添加编辑说明字样。
6. 形成未来写作规范、模板及校验。硬错误阻止构建，文风建议供编辑判断，不采用机械字数配额或自动删改。

## 第二阶段：其他文章与入口

1. 编写 ISO 周 38–42 的 5 篇周报，围绕关联变化归纳，不把日报列表当作周报正文。第 38 周明确现有归档只有 3 天；所有周报绑定原始日报哈希。
2. 新增 3 篇完整独立文章：Gaussian-Splat-Lite 1.3.1 工具解读、ResStreamGS 论文解读、高斯格式互操作专题。固定一手来源，说明 AI 辅助及未独立实验的范围。
3. 将独立文章接入工具、论文、主题、相关日报和搜索。保留原有内容类别语义，使用独立文章标识区分条目。
4. 检查搜索、目录、展开、旧锚点、图片预览、首页卡片进入/返回、RSS 和归档；覆盖桌面、平板横竖屏、手机、明暗主题和减少动态效果。

## 验证与交付

运行 Python 内容及媒体测试、站点测试、TypeScript 检查、编辑提示、静态构建和导出链接验证。人工检查代表性页面并保存截图。记录失败与修复、未执行的真实设备/性能测试及来源缺口。

交付内容规范、30 篇样本清单、31 份阅读版、5 篇周报、3 篇独立文章、实现与测试、可查看的本地站点和至少一个本地 checkpoint。保留研究记录与相关未跟踪资料；不 push、不开 PR、不部署、不改远端自动化。
