# 少数派行文与排版研究

观察日期：2026-10-19。研究用途是总结可迁移的编辑方法；不复制第三方文章全文、付费内容或品牌素材。

## 样本观察

30 篇中共 191 条主要新闻，每期 4–9 条；阅读时间为 5–14 分钟，中位数 8 分钟。主要新闻共 562 个自然段，每条 1–8 段、中位数 3 段。段落长度中位数 153 字符，四分位约 108/215 字符；66 段超过 300 字符，8 段超过 500 字符。因此不应把“每段固定字数”“每条固定三段”作为自动发布门槛。

24 篇有简讯模块；191 条主要新闻中 93 条配图，187 条带来源链接。图片并非每条必需，也不应为对齐数量填入泛用装饰图。样本中较长参数段和宣传措辞仍需编辑判断，不因为来自参考站就照搬。

## 可迁移的规律

1. 标题先给具体变化，首段交代主体与事件；后续解释用途、背景和条件。信息按读者理解顺序展开，研究过程不直接当正文。
2. 速览帮助定位，主要新闻展开解释，简讯缩短篇幅。不同层次承担不同任务，避免用导读表再完整复述一次正文。
3. 自然段是主要承载形式。列表服务并列与步骤，表格服务真实对比；小标题需要有具体意义。
4. 来源贴近事实，作者评价应有依据。项目“发布”“开源”“可跑”“亲测”不可混用；技术文章尤其要交代测试口径。
5. 排版保持可读行宽、稳定段距、清晰标题层级、图片及图注关系。实测桌面正文约 680px、17px 字号/30.6px 行高；普通文章 H2 为 32px/44.8px。高斯日报采用相应桌面节奏，手机正文用 16px/28.8px，并保留日报更紧凑的事件标题。

## 本项目的具体转化

- 31 期研究原文保持原始字节，阅读版按事件重组。重复监控与无变化记录留在可访问归档中。
- 主新闻写变化、用途、状态与限制。技术参数、实验条件和可重复步骤进入有标题的深读块，关键结论仍在可见正文。
- 工具解读、论文解读和专题分别回答工作流、方法证据与跨工具问题；周报提炼一周联系。
- 搜索同时保留中文阅读标题和原文可验证题名。原始链接及论文归档身份不因文风调整而改变。
- AI 参与范围和未执行的实验公开说明。素材版本在仓库记录，页面只呈现图片内容与来源；未宣称复现的软件/设备指标不改写成亲测。

以上规律对应 `docs/editorial-style.md`；它们是编辑依据，不是对每条新闻段数、配图数或长度的硬配额。
