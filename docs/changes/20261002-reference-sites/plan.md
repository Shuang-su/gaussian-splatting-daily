## 实现方式

- **先保存原站依据。** 在桌面、平板和手机尺寸下逐屏浏览，保存整页截图、关键交互截图、DOM 结构、计算样式和资源清单。记录字体、字重、行高、内容宽度、图片裁切、间距、圆角、边框、阴影、吸顶行为和断点变化。页面与素材均记录原始网址和采集时间，后续比对使用同一份内容。
- **建立独立可编辑工程。** 在当前日报工作区 `/Volumes/Prism/gaussian-splatting-daily-preview-20260930T172319Z/project` 的 `codex/reference-sites` 分支新增 `reference-sites/`，使用 React、TypeScript、Vite，包含两套独立应用和样式。页面内容、组件、样式与资源映射分开管理，依赖通过锁文件固定。现有 Next.js 门户及其内容构建接口保持原状。
- **按页面实际表现复刻。** 少数派首页卡片、派早报列表、日报正文分别还原；Radiance Fields 的桌面头条并排图文、手机头条顺序和紧凑新闻列表分别实现。圆角与主题逐页对应原站；只有原站实际提供的暗色状态才进入参考站。
- **采用真实素材。** 保存页面使用的图片、图标、SVG 和可获取字体，页面从本地资源加载。资源映射记录来源、文件、尺寸和校验值；缺失或替代的素材单独记录。参考站素材与高斯日报的报道配图分别管理。
- **完成阅读相关交互。** 还原导航、手机菜单、搜索展开与结果、列表筛选、加载更多、目录跳转、返回顶部，以及少数派图片预览的工具栏、缩略图、切图、缩放、旋转和拖动。键盘与关闭后的焦点、滚动恢复一并验证。具体行为以原站实际操作为依据。
- **使用固定的本地数据。** 列表保存首批及下一批真实条目，搜索和筛选在这些样本中运行，覆盖正常结果与空结果。7 页之间使用本地链接，范围外内容保留原站入口。登录、评论提交、支付与订阅等服务行为不连接真实后台；个人账户资料不进入参考数据。

实施顺序为：先完成少数派日报的整篇阅读与图片预览，再完成少数派首页和列表；随后完成 Radiance Fields 首页及其余三页。

## 少数派补充研究与后续改版依据

7 页之外，继续查看少数派的普通文章、Matrix、栏目与作者入口，重点比较普通文章和日报在标题、作者信息、目录、图片组合、注释、推荐内容上的区别。这部分保存截图、结构记录和结论，暂不扩展首轮复刻页面。

写作流程沿已确认有效的官方入口研究：[文章创建与编辑](https://manual.sspai.com/guides/using-the-editor/)、[提交与审阅流程](https://manual.sspai.com/guides/review-procedure/)、[风格指南](https://manual.sspai.com/rules/manual-of-style/)。整理标题与摘要、题图、图注、正文层级、引用来源、草稿、预览和纠错的做法，为高斯日报后续编辑流程提供依据。

完成后形成一份对应表：**原站页面或组件 → 实际行为与尺寸 → 现有高斯日报的差异 → 建议调整的位置**。阅读结构优先参考少数派日报；首页信息组织、论文与工具列表同时对照 Radiance Fields。具体改版方案在两套参考站完成后确定。

## 验收与交付

- **视觉：** 在 375、390、430、768、1024、1440 像素宽度检查全部 7 页；1440 和 390 保存整页对照图，其他尺寸保存布局变化处。原站与本地使用相同内容、视口和状态，逐项核对换行、对齐、留白、圆角、图片比例及浮动元素。
- **交互：** 验证完整阅读路径、菜单、搜索、筛选、加载更多、目录、图片预览和键盘操作。实际手机手势与浏览器模拟结果分别记录；未经设备测试的行为明确列出。
- **本地运行：** 两套应用通过类型检查和构建，详情页可直接打开与刷新。断开外部资源请求后，本地页面、图片、字体和核心交互仍可使用。
- **现有成果：** 核对本轮差异，保护 13 期 Markdown、索引、图片来源记录、Metaflow 标识和既有发布修复。参考站代码与素材不进入高斯日报的生产构建。
- **交付物：** 两套可编辑源码、固定内容与资源清单、原站和本地截图、差异记录、少数派补充研究、本地 checkpoint SHA。默认预览端口分别为 `4340`、`4341`，交付时提供经过实际打开验证的地址与重启命令。大型采集资料保存在项目内的 `.codex-work/references/`。

本轮以本地参考站和研究交付为完成边界，公开 PR、部署和定时发布继续留在原发布计划中。
