# 用户请求 · 2026-11-13

在本地高斯日报预览仓库实施跟手返回、稍后阅读和封面补齐。通过三位 Sol 子代理并行处理，在仓库建立细分 Issue，上传参考链接、相关图片视频及分析，完成后提供 4337 本地预览与 checkpoint。

1. 稍后阅读从右下入口展开纵向弧形封面，突出中间一项，同时显示标题、摘要、日期、继续阅读和移除。支持触摸、滚轮、键盘、查看全部、移除和撤销。用本机列表替换旧收藏，一次迁移，移出后刷新不复活。只保存文章标识和展示信息，关闭回到入口，打开文章由正文接管焦点。
2. 日报、独立文章和有正文的编辑周报记录最后看到的正文段落或图，重开或刷新恢复。仅恢复未读完位置后，页头出现主题色「从头开始阅读」，点按回到包含封面的开头并聚焦标题。正文末端清除进度。显式章节、浏览器前进后退及评论登录回跳优先，字号和窗口变化保住原位置。
3. 平板和折叠屏使用现有路径验证多级页面。普通导航可保留上一级与更早的返回层，卡片或列表能展开时使用展开路径。宽屏初值 960 CSS px，正文至少 600 CSS px。按浏览器报告的折缝使用连续屏区。保持真实链接、独立滚动、筛选、选中项、直达、返回与历史。文章之后是否另开一级留待明确用途。
4. 顶部下拉用近 100 ms 的速度和加速度判断短甩、刹车、长拉。长拉 116 px，短拉 42 px 起判，最多预测 96 px。正文中间可右滑退场，下拉仍从当前位置缩回来源卡片。两者恢复来源列表、滚动、焦点和轮播，玻璃控件保持固定。排除系统边缘、选字、图片预览、横向滚动区、表单、弹层和多指，减少动态时提供原返回入口。
5. 目录、讨论、稍后阅读底部面板支持把手跟手拖动、遮罩联动、上拉阻力、可中断的释放弹簧、关闭按钮及 Escape。按现有入口优化搜索、字号、更多和分享的过渡与焦点。
6. 参考久石让页的下缘渐隐和上滚失焦，保护标题、日历和玻璃控件清晰。少数派首页复测后恢复轮播 16 px 内缩、8 px 段距、2 px 细线，暂停放在封面右下。补 10 月 19、20 日和 10 月 25 日至 11 月 13 日共 22 期封面，优先一手图，其余使用独立登记的 ImageGen 编辑插画。正文图应解释实际操作、方法或结果。
7. 内容、媒体、类型、站点测试、静态导出、手机/桌面/平板浏览器和实体设备分别验收。四段 10 位 BT.2020 PQ 原录屏校色后用于比对，HDR 亮度及触摸手感在实体设备验收。
