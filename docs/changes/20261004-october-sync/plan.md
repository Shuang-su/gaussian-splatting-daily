# 本地同步步骤

1. 在 `codex/daily-october-sync` 保存远端三期原文快照和校验值。仅导入缺少日期，不合并远端工作流或覆盖本地文章改版。
2. 保持三期正文逐字节一致，通过可选 frontmatter 将源段落分配到事件。沿用原优先级和判断，保留所有链接、栏目定位和论文身份；填写完整短摘要、项目标签与列表元数据。
3. 选取报告日期之前存在的相关真实图片，保存固定来源和原图；使用现有 Sharp 生成不放大的响应式 WebP。封面及对应事件共享图片身份。
4. 合并 10 月纠错记录，保留已有 9 月纠错；更新月份入口、归档索引和归档 checkpoint。checkpoint 仅说明远端归档进度，不代表 Pages 上线或定时发布验收。
5. 校验 16 期完整覆盖、原文保真、事件和旧锚点、封面及来源。执行现有 Python、网站、类型和静态导出检查，在桌面和手机实际打开新首页、列表和文章。
6. 本轮本地预览保持开始前的每日、每周 RSS 文件不变。生成其他内容数据后恢复这两个文件，再构建 Next.js；记录冻结校验值。正常构建器未改变，排版确认后再处理订阅产物。
7. 保存截图与验证记录，创建本地 checkpoint。交付准确预览地址、提交 SHA 和未运行项；不 push、不发 PR、不部署。
