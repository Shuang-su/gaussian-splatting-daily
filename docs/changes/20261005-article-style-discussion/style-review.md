## 审查中另外修正

9 月 30 日研究归档插入了一个与正文分组重复的 `group-brief`。排重原先只识别 bodyHtml，没有计入 ArticleEvents 生成的分组容器。现在将实际分组加入排重集合，回归测试也改为验证组件渲染结果；旧链接继续跳到正文简讯，不打开研究归档。

## 有意保留的差异与边界

- 按既定计划保留 680px 最大正文宽度，不把参考网站所有文末区的宽度机械复制到本站。
- 事件讨论原位展开；没有复制参考网站账号体系、真实读者留言、付费充电或外部发帖行为。
- giscus 仍是未配置状态；真实登录、写入、真实数据摘要及计数的接入留待单独发布阶段。样本只接受精确 localhost / 127.0.0.1 / [::1]，普通公开域名忽略参数。
- 内容与正文来源没有重写，16 期研究 Markdown 和 4 期阅读 Markdown 均保持原字节；RSS 两个文件保留改动前 SHA-256。
