# 高斯日报：卡片展开进入文章与返回交互优化

2026-10-18，用户批准的完整实施计划。交付限于本地预览与 checkpoint。

## 实施期间的用户修订（优先适用）

用户在预览后要求列表同样展开、描述文字参与过渡，以及接近 Motion App Store 示例的整卡片展开到全屏。以下修订替代原计划中对应的时长和文字过渡细节，其余范围与行为不变：

- 外层表面展开到整个阅读视口；封面、标题、描述和日期牌按各自真实几何位置衔接，原文章阅读宽度和正文排版保留。
- 使用物理弹簧：进入 stiffness 180 / damping 24 / mass 1.1，约 800ms 收稳；返回 300 / 30 / 1，约 550ms 收稳。主要位移更早完成，余下时间保留平滑收尾。输入和滚动不等待动画结束。
- 描述与标题使用单份文本代理，字号、行高、字距和位置随弹簧衔接，避免不同换行的双份文字重叠。长正文不复制、不缩放。
- 列表缩略图已经可用时立即参与展开，不等待大图解码；大图仍在加载时使用原缩略图暂时填充真实封面。已知失败、缺图、不同封面或失效几何仍走短淡入。
- 点击到路由就绪之间先提供轻微抬起反馈；新页面在布局阶段先遮住，再在卡片表面内显现，避免真实标题抢先闪出。
- 验证材料以 `.codex-work/evidence/article-card-transitions/revised/` 中最终版本为准；上一级目录中的旧节奏录帧保留为修改过程证据，不视为最终效果验收。

以下保留用户最初批准的计划原文，便于追溯。

## 一、目标与已确定方向

将「首页／列表卡片 → 完整文章页 → 来源位置」做成连续、有明显展开感的阅读体验。保留现有文章版式、网址和长文阅读方式，手机端使用返回按钮与系统返回。

以 [Motion App Store 示例](https://motion.dev/examples/react-app-store) 和 [B 站卡片展开教程](https://www.bilibili.com/video/av796815127) 为形变参考，可以尝试直接使用或者复刻其代码；[Atlas 的 X 演示](https://x.com/sekachov/status/2108601480634880431) 用于参考快速响应的体验，其作者提到的具体实现技巧尚未公开。

- 进入约 **450ms**，退出约 **320ms**，使用轻微弹性。
- 点击立即反馈，路由加载与动画协调进行，正文就绪后即可阅读。
- 同时修复已观察到的轮播返回问题：从某一期进入文章后，返回应恢复该期，而不是重置到第一张。

## 二、交互行为

- **入口覆盖**：首页轮播、首页日报列表、日报归档、搜索中的日报结果和文章底部的往期卡片，统一接入过渡。
- **展开过程**：卡片背景、封面、标题和日期牌分别衔接到文章首屏的真实位置。封面保持比例并调整裁切；标题换行与字号变化通过位置动画和交叉淡化衔接；正文按最终排版出现。
- **返回入口**：文章页头 Logo 前增加至少 44×44px 的返回控件，沿用现有页头的显示／隐藏行为。有有效来源时返回来源；直接打开文章时显示“返回日报列表”。
- **退出过程**：文章封面仍在视口内时，反向收回原卡片。阅读到正文深处时，使用约 120ms 淡出并恢复来源列表，原卡片短暂显现反馈，不先滚回文章顶部。
- **位置恢复**：恢复来源网址及查询参数、列表栏目、加载数量、滚动位置、轮播期次、暂停状态和键盘焦点。恢复完成后再测量卡片位置；轮播在过渡期间暂停，结束后按原状态继续。
- **历史行为**：站内返回一次回到来源，即使阅读期间跳转过多个章节。浏览器前后退保留正常的锚点历史语义，抵达来源页时执行位置恢复；历史导航不额外叠加一次收起动画，避免与系统返回手势重复。
- **章节直达**：论文、工具等带 `#anchor` 的入口保留目标章节，采用短淡入和相同的来源恢复机制；只有同一日报封面与文章首屏之间执行封面展开。

## 三、实现方式与边界

- 使用 **Motion 14.3.0**，在根布局增加常驻过渡控制器。现有 Next.js 页面、静态导出和文章组件继续负责内容；过渡层只承载短暂的卡片视觉副本，通过实测位置和尺寸进行动画。
- 增加统一的文章链接接入点与目标注册接口，记录“来源页面＋入口实例＋日报 ID”。同一文章同时出现在轮播和列表时，返回准确对应本次点击的入口。
- 来源快照使用独立的会话存储，兼容现有首页恢复状态。历史标记合并进现有 `history.state`，保留 Next.js 字段；章节跳转同步保留来源标记。
- 保持 `/gaussian-splatting-daily` 前缀、独立文章 URL、公开锚点、SEO 元数据和静态 HTML。鼠标中键、修饰键、新标签页及 JavaScript 不可用时继续遵循普通链接行为。
- 动画允许中断：重复点击同一目标不增加历史记录；返回或新的导航接管当前过渡；用户开始滚动时结束视觉代理并显示真实页面。代理不截获指针，不进入无障碍树。
- 减少动态效果时取消缩放和弹性，保留导航、位置及焦点恢复。图片失败、来源不存在、视口变化导致几何失效时采用短淡入；过渡异常必须清理代理并交还正常导航，不能留下遮挡层或空白页面。
- 本轮保持现有正文、内容索引、RSS、菜单、搜索面板、目录和图片预览的功能边界，不加入下拉关闭手势。

## 四、验证与交付

- **行为测试**：覆盖来源识别、轮播与列表状态恢复、重复点击、快速进出、章节历史、直接访问、无图卡片、失效来源，以及会话存储不可用。
- **浏览器验收**：在指定浏览器检查手机 390／430px、平板 820px、桌面 1440px，覆盖浅暗色与减少动态效果；核对进入、中间帧、退出及最终落点。
- **关键场景**：非首张轮播进入后返回；加载更多后进入并返回；搜索筛选后返回；文章深处退出；多个章节跳转后点击返回；浏览器前后退；进出过程中改变窗口尺寸。
- **体验标准**：本机浏览器预取命中时，点击后的首个可见反馈目标为 100ms 内；没有空白闪帧、封面拉伸、标题重影、重复导航或返回后跳动。用连续帧核对约 450／320ms 的节奏；手机系统返回保留真实设备验收。
- **工程检查**：运行网站测试、TypeScript 检查、静态构建及现有导出校验；比对正文、索引与 RSS 基线，确认链接、锚点和资源完整。
