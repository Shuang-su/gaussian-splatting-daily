原站本次复查的工具滚动加载曾出现显示数量超过总数的状态，因此未用该批次替换已经冻结的内容。首页轮播关闭自动切换，图文与日期使用固定快照。RF 首页原有长篇介绍和页脚均保留。

## 静态产物和工程

执行 `npm run build`（包含 TypeScript）、`npm test`、`npm run verify`。前两站各自构建，脚本为七个详情路径输出独立 `index.html`。另外用普通 Python 静态服务器实际打开七个导出路径，刷新两篇详情页，并禁止外部 HTTPS 请求 / 关闭缓存；111 个请求中没有外部请求，七页均显示正文且无失败图片。记录见 `qa/static-offline.json`，临时的 4342 / 4343 服务器已关闭。

3 项纯函数测试覆盖中文 URL、组合关键词和响应式边界。资源校验覆盖 820 个本地文件及模板引用，未调用高斯日报生产构建。

整页截图曾在相对样式链接下丢失样式；已改为当前站点的绝对样式地址并重拍，保留正常浏览器渲染。少数派页脚的累计差异来自 `--height-SsCustomFooter`，用 ResizeObserver 同步真实页脚高度后，1440 / 390 页面高度一致。

没有公开 PR、推送、合并、Pages 部署、定时发布或实际手机验收。本轮不宣称完成这些工作。

Node.js 26.3.0 下 tsx 提示 `module.register()` 的弃用警告，测试退出码为 0；不是浏览器错误。
