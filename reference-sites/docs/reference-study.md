本报告描述 2026-10-02 至 10-03 实际打开的页面。首轮七页的内容按采集批次冻结，不将网站新闻正文视作本报告已独立核实的新闻事实。页面来源见 `public/data/pages.json`，完整截图和计算样式见项目 `.codex-work/references/source/`。尺寸均为 CSS 像素。

## 官方写作流程

[文章创建与编辑](https://manual.sspai.com/guides/using-the-editor/)说明标题层级、并排双图和图注、Markdown 导入、草稿和发布前预览。预览依赖先保存；手册当时说明草稿没有自动保存和版本历史。高斯日报继续使用本地 Markdown 与 Git 保存修改，预览必须针对本次已保存版本。

[提交与审阅流程](https://manual.sspai.com/guides/review-procedure/)区分社区直接发布与编辑部投稿，后者经过处理再决定展示。对高斯日报的对应关系是区分研究、归档校验、合并与部署状态；页面可预览不代表公开发布已经成功。

[风格指南](https://manual.sspai.com/rules/manual-of-style/)强调标题层级连续、一手来源、引用附近标注出处、图片与正文对应，图注不承载正文没有交代的新事实。应用到日报时，事件标题写项目与变化，短摘要独立撰写，来源紧邻事实，修正保留记录。

两份官方文档的题图尺寸并不一致：编辑指南推荐 **4:3、1600×1200**；风格指南仍列普通 **1420×708** 和醒目 **708×708**。本轮并列记录，不把其中任一数字当作统一现行规范。高斯日报应先确定自己的真实展示比例，再选图与裁切；不得通过拉伸图片适配。

尚未制定下一轮高斯日报改版的最终组件方案。本地参考站让标题、留白、封面、目录、正文和图片预览可以被连续比较，下一轮应从一篇日报的完整阅读开始验证。
