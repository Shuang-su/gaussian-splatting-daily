# 少数派修复验收

2026-10-03。工作区：`codex/reference-sites`。修复前 HEAD：`81c3541337e984fdf1572966b023ddb48fc404ae`。浏览器：macOS Codex 内置浏览器。

本轮复核了首页、派早报列表与 `/post/115197` 的连续阅读流程。首轮将三份 HTML 在断点间整体替换，导致筛选、加载数量、焦点和图片预览重置；当时静态高度相同不能排除这些问题。该载入方式已从少数派页面移除。

## 实际变更

- 少数派采集结构转换为 React 节点；桌面、平板、手机共享一次挂载的 Header、文章、列表和 Footer。筛选、加载数量由 React 管理，返回时恢复已加载内容和滚动位置。
- 根据原站补采 5 组桌面与 5 组手机二级菜单。共创、PRIME、Matrix、栏目、Pi Store 保留不同内容和布局，图片来自原菜单。新增 17 个资源，来源、尺寸与 SHA-256 纳入 `public/data/assets.json`。
- 范围内首页、日报列表、指定日报保留本地链接；范围外路径指向原站。手机 Matrix 先展开菜单，不再进入本地缺失页面。
- 手机与平板使用原站目录按钮；桌面保留侧边目录。标题滚动留出 76px，恢复原站向下隐藏、向上出现的导航。
- 桌面搜索使用原站遮罩。搜索结果中 Esc 关闭并恢复焦点，避免 focusin 再次开启；RF 共用搜索也复核该操作。
- 外观选择支持键盘、保存和刷新；关注无本地条目时显示空状态。轮播拖动取消链接误触，隐藏菜单的轮播在显示后测量尺寸。
