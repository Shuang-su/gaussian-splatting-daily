# Contributing

## Daily content

Daily content lives under docs/daily/YYYY/MM/YYYY-MM-DD.md.

For factual corrections to a merged Daily, open a Correction Issue first and link the correction PR to it.

## Automation

Changes to source collection, validation, GitHub Actions permissions, or AI prompts should be reviewed more carefully than ordinary content edits.

## Large assets

Do not commit large Gaussian Splat, video, or model binaries. Commit metadata, attribution, checksum, poster image, and an external object-storage/CDN URL instead.
